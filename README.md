# Analysis Scripts for "Defined human tri-lineage brain microtissues" Manuscript

This repository contains the single-cell and single-nuclei RNAseq analysis scripts that produced the results shown in the manuscript "Defined human tri-lineage brain microtissues" by Uenaka T. et al. (currently under review).

The available scripts can be divided into four categories, namely:
- Processing (incl. clustering) of single-cell and single-nuclei RNAseq data from human tricultures (files "scRNAseqAnalysis.R" and "snRNAseqAnalysis.R")
- Integration of single-cell and single-nuclei RNAseq data with publicly available datasets (files "Analysis_GSE179590.R", "Analysis_scOrganoids.R" and "Analysis_Linnarsson.R")
- Differential Expression analysis between triculture-derived single-cell and single-nuclei RNAseq data and publicly available datasets (file "DiffExp_OtherStudies.R")
- Additional plots that are part of the manuscript (file "AuxPlotting.R")

A link to the manuscript will be included in this repository once it is published.
